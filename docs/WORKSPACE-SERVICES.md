# Shared workspace services

A small common commit bundled in the library and docking branch histories provides a presentation-state selection feed and bounded native error logging. It has no feature dependency, persistence, inference, or execution behavior. The existing native_logs_workspace_error command identifier is preserved. Model library and monitoring can be adopted without contextual Chat.

Cherry-pick this common commit once before either module; merging both branches recognizes the shared ancestry. The feed is optional reference data, not authority to render. It must not receive credentials or raw graphs.
